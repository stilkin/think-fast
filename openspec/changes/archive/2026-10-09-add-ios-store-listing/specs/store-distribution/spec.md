# Spec Delta

## ADDED Requirements

### Requirement: The iOS listing lives in the repository and is pushed through documented interfaces
The App Store listing content SHALL live in the repository — copy and age-rating answers in `store.config.json`, screenshots as script-generated assets — and SHALL reach the store only through documented interfaces. Store-side fields with no programmatic interface SHALL be entered manually and enumerated in the repository.

#### Scenario: Listing content is reproducible from the repo
- **WHEN** the listing copy or screenshots need a change
- **THEN** the copy is edited in `store.config.json` and the screenshots regenerated by script — nothing is hand-entered on the store side except fields the stores expose no interface for

#### Scenario: Store interfaces are used carefully
- **WHEN** a step touches the App Store Connect API
- **THEN** the endpoint and payload match Apple's published OpenAPI specification, reads precede writes, and any unexpected response stops the step for review instead of being retried

#### Scenario: The manual remainder is explicit
- **WHEN** the listing is complete
- **THEN** the few manually-entered items (e.g. pricing, the data-collection label) are enumerated in the repository rather than silently diverging from it
